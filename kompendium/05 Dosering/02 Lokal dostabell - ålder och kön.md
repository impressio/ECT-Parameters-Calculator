# Lokal dostabell: ålder och kön

I er verksamhet används en ålders- och könsbaserad dostabell. Den anger laddning i mC och ska skiljas från [[04 Empirisk titrering|empirisk titrering]] av kramptröskeln; metoderna jämförs i [[01 Doseringsmetoder|Doseringsmetoder]].

Tabellen följer kalkylatorns laddningskontroll på [ect.matty.se](https://ect.matty.se/?lang=sv), som bygger på MECTA-kolumnen i *ECT-behandling*, verksamhet Rättspsykiatri, dokument-ID SU9806-1988473940-61, version 5.0, s. 7. Den lokala PDF-kopian är daterad 2025-02-10 och anger giltighet till 2027-02-10. Kalkylatorn ger varje ålder från 18 år ett intervall: 18-29 år har egen rad, och vid exakt 40, 50 och 60 år gäller hela spannet för båda angränsande åldersgrupper.

| Ålder | Kvinnor: laddning<br>(mC) | Män: laddning<br>(mC) |
| :--- | :--- | :--- |
| 18-29 år | 180-280 | 190-290 |
| 30-39 år | 280-320 | 290-380 |
| 40 år | 280-380 | 290-420 |
| 41-49 år | 320-380 | 380-420 |
| 50 år | 320-530 | 380-570 |
| 51-59 år | 380-530 | 420-570 |
| 60 år | 380-650 | 420-1000 |
| Över 60 år | 530-650 | 570-1000 |

Laddningen bestämmer inte ensam pulsbredd, frekvens, duration och strömstyrka. Samma mC kan erhållas med olika parameterkombinationer. Läkarordinationen behöver därför ange elektrodplacering och avsedda inställningar. Tabellen anger inte i sig någon uppmätt kramptröskel eller multipel av tröskeln.
